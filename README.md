# AudioFix — Revenge Plugin

Плагин для блокировки переключения Bluetooth-наушников из A2DP в HFP/SCO режим при входе в голосовые каналы Discord.

## Быстрый старт

Вставь эту ссылку в Revenge → Plugins → Add:

```
https://Nek962.github.io/my-revenge-plugins/AudioFix
```

## Документация

Полная документация находится в папке [`AudioFix/`](./AudioFix/README.md).
